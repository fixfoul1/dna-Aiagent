# 🧬 DNA Mutation-Detection AI Agent

An end-to-end Bioinformatics AI Agent that aligns DNA sequences, identifies mutations (substitutions, insertions, deletions), and translates raw genomic data into human-readable biological insights.

Built with **Python**, **Biopython**, **Google Gemini API**, and **Streamlit**.

---

## ✨ Features
* **Deterministic Sequence Processing:** GC Content calculation, reverse complements, and DNA translation using Biopython.
* **Global Sequence Alignment:** Classifies mutations with exact alignment positioning.
* **Automatic Function Calling (AFC):** Uses Gemini 3.6 Flash to orchestrate tools intelligently based on user queries.
* **Web Dashboard:** Interactive user interface powered by Streamlit.

---

## 🛠️ Tech Stack
* **Language:** Python 3.11+
* **Bioinformatics:** Biopython
* **LLM Orchestration:** `google-genai` SDK
* **Frontend UI:** Streamlit
